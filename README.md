A tiny program that writes one two-line robot apology to a text file.
The first line owns a specific mistake — painting over the pencil marks
on the doorframe that tracked how tall the children had grown — and the
second line names the lesson and the changed behaviour: photograph a wall
before painting it, so the marks live on in a picture.

## Run it

```sh
python3 main.py
```

It writes the apology to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
